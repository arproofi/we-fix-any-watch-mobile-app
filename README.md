# We Fix Any Watch Mobile App

This is a React Native mobile app for the We Fix Any Watch website, providing watch repair services.

## Features

- Home screen with branding and main call-to-actions
- Services screen with detailed watch repair services
- Contact screen with a form to submit queries
- Testimonials screen with customer reviews
- FAQ screen with frequently asked questions
- Bottom tab navigation
- Tailwind CSS styling
- Google Fonts and Font Awesome icons

## Setup and Running

1. Ensure you have Node.js and npm installed.
2. Install Expo CLI globally if not already installed:
   ```
   npm install -g expo-cli
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Run the app:
   ```
   npm start
   ```
5. Use Expo Go app on your mobile device or an emulator to view the app.

## Notes

- Images are loaded from the official website URLs.
- The contact form currently shows an alert on submit; backend integration can be added as needed.
- Tailwind CSS is used via `tailwindcss-react-native`.

## Dependencies

- React Native
- Expo
- React Navigation
- Tailwind CSS for React Native
- Font Awesome React Native
